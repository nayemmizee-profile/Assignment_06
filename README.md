# FitLog

FitLog is a simple fitness and workout tracking web application. It helps users explore different exercises, create their workout plan, and keep track of their daily workout activities in one place.

## Technologies Used

* **Next.js** – Used to build the web application and handle routing.
* **React.js** – Used to create reusable and interactive components.
* **JavaScript (JSX)** – Used for the main application logic and UI.
* **Tailwind CSS** – Used to design and make the interface responsive.
* **REST API** – Used to fetch exercise and workout data dynamically.
* **Vercel** – Used to deploy the application.

## Key Features

1. **Exercise Library**
   Users can browse different exercises and see useful information such as muscle groups, equipment, difficulty, duration, calories, sets, and reps.

2. **Add Exercises to My Plan**
   Users can select exercises from the workout library and add them to their personal workout plan.

3. **Today's Workout Plan**
   The My Plan page shows the exercises selected for the current workout along with basic statistics such as total exercises, workout time, and calories.

4. **Save Exercises**
   Users can save exercises they are interested in and access them later without having to search for them again.

5. **Dynamic and Responsive UI**
   The application uses dynamic data from an API and the interface is designed to work smoothly on desktop, tablet, and mobile screens.
